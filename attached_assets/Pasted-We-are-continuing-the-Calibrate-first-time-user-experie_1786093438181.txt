--------------------------------------------------
GOAL
--------------------------------------------------

The Starting Hypothesis screen should clearly communicate:

1. Onboarding is complete.
2. Calibrate has chosen a useful technique to TEST FIRST.
3. This recommendation is only a starting hypothesis.
4. The recommendation can change based on real study-session results.
5. The student is NOT ready for a Study Session yet.
6. The next step is to create/set up their first subject.

The correct journey should become:

Start
→ How It Works
→ Onboarding
→ Starting Hypothesis
→ Set Up First Subject
→ Add Material
→ Generate Questions
→ Review / Approve Questions
→ Study Session
→ Feedback
→ Insights

This task only handles:

Starting Hypothesis
→ Set Up First Subject

Do not implement the later material, ML, Question Bank, or Study Session steps yet.
